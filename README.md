# LLM Security Tester

Three-agent (Attacker, Judge, Defender) security testing app for LLM system prompts,
aligned with OWASP LLM Top 10 2025.

## Stack
- LangGraph (multi-agent orchestration)
- Groq (openai/gpt-oss-120b)
- Streamlit (UI)
- SQLite (users)

## Features
- User registration + login (bcrypt + SQLite)
- 3 AI agents: Attacker, Judge, Defender
- Live chat test screen
- OWASP LLM Top 10 2025 categories

## Deploy
Deployed on Streamlit Community Cloud.
